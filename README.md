# 🎲 Do Zero à Aventura: Guia Prático para Criar sua Primeira Ficha de D&D

> Caderno temático desenvolvido com apoio do NotebookLM para auxiliar jogadores iniciantes a compreender e preencher sua primeira ficha de personagem de Dungeons & Dragons.

---

## 📌 Sobre o Projeto

Este projeto foi desenvolvido como parte de um desafio da DIO com o objetivo de explorar a Inteligência Artificial como ferramenta de aprendizagem ativa.

A proposta consiste na criação de um Caderno Temático utilizando o NotebookLM, reunindo fontes selecionadas sobre Dungeons & Dragons (D&D) e utilizando engenharia de prompts para transformar essas informações em um guia didático para jogadores iniciantes.

O foco do projeto é explicar, de maneira simples e progressiva, os principais conceitos necessários para criar uma ficha de personagem e compreender as decisões envolvidas nesse processo.

---

## 🎯 Objetivos

### Objetivo Geral

Criar um guia de primeiros passos para auxiliar jogadores iniciantes na criação e preenchimento de uma ficha de personagem de D&D.

### Objetivos Específicos

- Compreender a estrutura de uma ficha de personagem;
- Explicar os principais conceitos utilizados durante sua criação;
- Apresentar um passo a passo para o preenchimento da ficha;
- Identificar as principais dúvidas de jogadores iniciantes;
- Utilizar o NotebookLM como ferramenta de apoio aos estudos;
- Testar diferentes estratégias de prompts;
- Avaliar a qualidade das respostas produzidas pela IA;
- Identificar dificuldades e limitações encontradas durante os testes;
- Criar um conjunto de prompts reutilizáveis para futuras consultas.

---

## 👥 Público-Alvo

Este material foi desenvolvido principalmente para:

- Pessoas que nunca jogaram D&D;
- Jogadores iniciantes;
- Pessoas que possuem dificuldade para interpretar uma ficha de personagem;
- Jogadores que desejam entender melhor as decisões envolvidas na criação de um personagem.

---

## 🧠 Problema

Para uma pessoa que está tendo seu primeiro contato com D&D, uma ficha de personagem pode parecer complexa devido à quantidade de informações, termos e regras envolvidos.

Conceitos como atributos, modificadores, classe, perícias, proficiência, pontos de vida, classe de armadura e equipamentos podem gerar dúvidas durante a criação do personagem.

Este projeto busca organizar essas informações em uma sequência didática e acessível.

---

## 💡 Solução Proposta

Utilizar o NotebookLM como um tutor de estudos baseado em fontes previamente selecionadas.

O processo será dividido em:

1. Curadoria das fontes;
2. Inserção das fontes no NotebookLM;
3. Análise das informações;
4. Criação e teste de prompts;
5. Identificação de lacunas no conteúdo;
6. Busca por fontes complementares;
7. Validação das respostas;
8. Organização do conhecimento;
9. Criação do miniguia final.

# 🧪 Engenharia de Prompts

Durante o desenvolvimento do projeto serão testadas diferentes estratégias de prompts.

O objetivo não será apenas obter respostas da IA, mas entender como a formulação das perguntas influencia a qualidade, organização e profundidade das respostas.

## Prompt inicial

> Explique como criar uma ficha de D&D.

### Problema identificado

A pergunta é muito ampla e pode gerar uma resposta superficial ou pouco adequada para uma pessoa que nunca teve contato com D&D.

---

## Prompt aprimorado

> Explique passo a passo como criar uma ficha de personagem de D&D para uma pessoa que nunca jogou RPG. Explique cada conceito utilizando linguagem simples e apresente exemplos práticos.

### Resultado esperado

Uma resposta mais direcionada para iniciantes.

---

## Prompt detalhado

> Atue como um instrutor de D&D para jogadores iniciantes. Explique o preenchimento da ficha de personagem campo por campo, seguindo uma ordem lógica.
>
> Para cada campo:
>
> 1. Explique o que ele significa;
> 2. Explique o que deve ser colocado nele;
> 3. Explique como obter essa informação;
> 4. Apresente um exemplo;
> 5. Explique erros comuns que um iniciante pode cometer.
>
> Baseie as respostas prioritariamente nas fontes disponíveis neste notebook e indique quais fontes sustentam cada explicação.

# 🩹 Cicatrizes e Troubleshooting

Esta seção documentará os problemas encontrados durante os testes com o NotebookLM.

## Problema 1 — Respostas muito genéricas

### Situação

O primeiro prompt produziu uma explicação ampla sobre criação de personagens, mas não explicou detalhadamente como preencher cada campo da ficha.

### Solução

O prompt foi reformulado para especificar que a resposta deveria seguir o preenchimento da ficha campo por campo.

---

## Problema 2 — Explicações muito técnicas

### Situação

Alguns conceitos foram apresentados utilizando termos que podem ser difíceis para pessoas que nunca tiveram contato com D&D.

### Solução

Foi solicitado que o NotebookLM assumisse o papel de instrutor para iniciantes e utilizasse linguagem simples, exemplos e analogias.

---

## Problema 3 — Necessidade de fontes complementares

### Situação

Alguns conceitos não estavam suficientemente detalhados nas fontes inicialmente selecionadas.

### Solução

Foi utilizado um prompt para identificar lacunas de conhecimento e sugerir fontes complementares.

# 🎲 Miniguia de Estudo

## 1. O que é D&D?

Dungeons & Dragons é um RPG de mesa no qual os jogadores interpretam personagens em um mundo de fantasia, enquanto um Mestre conduz a aventura.

---

## 2. O que é uma ficha de personagem?

A ficha reúne as principais informações que representam um personagem dentro do jogo.

Ela contém informações como:

- Nome;
- Classe;
- Origem;
- Atributos;
- Perícias;
- Pontos de vida;
- Defesa;
- Equipamentos;
- Características;
- Informações de personalidade e história.

---

## 3. Escolha do conceito do personagem

Antes de preencher números e regras, é interessante pensar:

> Quem é meu personagem?

Por exemplo:

> "Quero criar um guerreiro que protege pessoas mais fracas e procura recuperar uma espada pertencente à sua família."

Essa ideia ajuda a orientar as decisões seguintes.

---

## 4. Escolha da classe

A classe representa uma das principais funções e capacidades do personagem.

Exemplos incluem:

- Guerreiro;
- Mago;
- Clérigo;
- Ladino;
- Bárbaro;
- Bardo;
- Druida;
- Monge;
- Paladino;
- Patrulheiro;
- Feiticeiro;
- Bruxo.

A escolha da classe influencia as habilidades e a forma como o personagem normalmente participa dos combates e aventuras.

---

## 5. Atributos

Os atributos representam diferentes capacidades do personagem.

Entre eles estão:

- Força;
- Destreza;
- Constituição;
- Inteligência;
- Sabedoria;
- Carisma.

Esses valores influenciam diversas ações realizadas durante o jogo.

---

## 6. Modificadores

Os modificadores são valores derivados dos atributos e são utilizados em diversas situações durante o jogo.

É importante compreender a relação entre:

**Atributo → Modificador → Teste**

---

## 7. Perícias

As perícias representam áreas específicas nas quais o personagem pode possuir conhecimento ou treinamento.

Exemplos:

- Acrobacia;
- Atletismo;
- Furtividade;
- História;
- Investigação;
- Percepção;
- Persuasão;
- Sobrevivência.

---

## 8. Equipamentos

O personagem precisa registrar os equipamentos que possui.

Dependendo da classe e das escolhas realizadas, esses equipamentos podem incluir armas, armaduras, ferramentas e outros itens.

---

## 9. Personalidade e história

Uma ficha não precisa representar apenas números.

Também é possível definir:

- Traços de personalidade;
- Ideais;
- Vínculos;
- Defeitos;
- História do personagem;
- Motivações.

Essas informações ajudam a transformar uma ficha em um personagem.

---

# ❓ Perguntas Frequentes

### O que é uma classe?

É uma das principais definições mecânicas do personagem, determinando suas capacidades e recursos.

### O que são atributos?

São valores que representam diferentes capacidades do personagem.

### O que é proficiência?

Representa treinamento ou especialização em determinadas áreas do personagem.

### O que são pontos de vida?

Representam a capacidade do personagem de suportar dano antes de ficar incapacitado.

### Preciso saber todas as regras antes de jogar?

Não. O objetivo deste guia é justamente ajudar novos jogadores a compreender os conceitos básicos gradualmente.

---

# 📖 Glossário

| Conceito | Definicao |
|---|---|
| Atributo | Valor que representa uma capacidade do personagem |
| Classe | Conjunto principal de capacidades do personagem |
| Perícia | Área específica de conhecimento ou habilidade |
| Proficiência | Treinamento ou especialização em determinada área |
| Pontos de Vida | Representação da resistência do personagem |
| CA | Classe de Armadura, utilizada para representar a dificuldade de atingir um personagem |
| Iniciativa | Valor utilizado para determinar a ordem de atuação durante o combate |
| Personagem | Papel interpretado pelo jogador dentro da aventura |
| Mestre | Pessoa responsável por conduzir a aventura e controlar o mundo do jogo |

# ♻️ Prompts Reutilizáveis

### Prompt para revisão

--> Explique novamente o conceito de [CONCEITO] utilizando linguagem simples e um exemplo prático para um jogador iniciante.

### Prompt para aprofundamento

--> Aprofunde o conceito de [CONCEITO]. Explique como ele se relaciona com outros elementos da ficha e apresente exemplos de situações em que ele é utilizado.

### Prompt para identificar erros

--> Quais são os erros mais comuns que um jogador iniciante pode cometer ao preencher [CAMPO DA FICHA]? Explique como evitá-los.

### Prompt para comparação

--> Compare [CONCEITO A] e [CONCEITO B]. Explique as diferenças, semelhanças e situações em que cada um é utilizado.

### Prompt para criação de personagem

--> Ajude-me a criar um personagem de D&D passo a passo. Antes de tomar cada decisão, explique as opções disponíveis, suas consequências e faça uma recomendação adequada para um jogador iniciante.
