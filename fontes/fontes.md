# 📚 Fontes do Projeto

Este arquivo reúne as fontes utilizadas para alimentar e validar o Caderno Temático desenvolvido no NotebookLM.

## 🎯 Critérios de seleção

As fontes foram selecionadas considerando:

- Confiabilidade;
- Relevância para criação de personagens;
- Acessibilidade;
- Clareza das explicações;
- Compatibilidade com a versão de D&D utilizada no projeto.
